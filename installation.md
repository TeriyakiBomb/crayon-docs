# Installation & Setup

Crayon is just some sass files, it'll work anywhere sass does. Its especially straightforward when used with vite.

::: code-group

```sh [npm]
$ npm install crayon-css sass-embedded
```

```sh [yarn]
$ yarn add crayon-css sass-embedded
```

```sh [pnpm]
$ pnpm add crayon-css sass-embedded
```

:::
