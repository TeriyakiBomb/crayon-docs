| Mixins | Purpose |
| --- | --- |
| `p-range`, `pt-range`, `pb-range`, `pl-range`, `pr-range` | Responsive padding on all or one side |
| `px-range`, `py-range` | Responsive horizontal or vertical padding |
| `m-range`, `mt-range`, `mb-range`, `ml-range`, `mr-range` | Responsive margin on all or one side |
| `mx-range`, `my-range` | Responsive horizontal or vertical margin |
| `gap-range`, `gap-x-range`, `gap-y-range` | Responsive gap, column gap, or row gap |
