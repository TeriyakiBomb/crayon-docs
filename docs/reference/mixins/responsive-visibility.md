| **Mixin**           | **Behaviour**                                      |
| ------------------- | -------------------------------------------------- |
| `show-from($name)`  | Hidden by default, visible at breakpoint and above |
| `hide-from($name)`  | Visible by default, hidden at breakpoint and above |
| `show-until($name)` | Visible by default, hidden at breakpoint and above |
| `hide-until($name)` | Hidden by default, visible at breakpoint and above |
