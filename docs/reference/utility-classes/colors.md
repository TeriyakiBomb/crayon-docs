### Colour utilities

| **Class**        | **Property**                |
| ---------------- | --------------------------- |
| `bg-{color}`     | `background-color: {color}` |
| `text-{color}`   | `color: {color}`            |
| `border-{color}` | `border-color: {color}`     |

### Colour opacity modifiers

| **Class**                  | **Property**                             |
| -------------------------- | ---------------------------------------- |
| `bg-{color}/{opacity}`     | `background-color: {color} at {opacity}` |
| `text-{color}/{opacity}`   | `color: {color} at {opacity}`            |
| `border-{color}/{opacity}` | `border-color: {color} at {opacity}`     |
